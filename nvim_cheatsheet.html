Neovim Cheatsheet

final_nvim_updates · All custom keymaps, plugins, and window management

Leader key = <Space>
File & Search (Telescope)
<leader>ffFind files in project
<leader>fgLive grep — search text across all files
<leader>fbBrowse open buffers
<leader>frRecent files
<leader>ftFind TODOs / FIXMEs (todo-comments)
-Open parent directory (oil.nvim)
LSP — Language Intelligence
gdGo to definition
grFind all references
KHover documentation
<leader>rnRename symbol across project
<leader>caCode actions (quick fixes, imports)
<leader>fFormat buffer (Java uses jdtls only)
:w (on save)Auto-format: JS/TS/CSS/HTML/Java/JSON
Diagnostics & Errors
]dJump to next diagnostic
[dJump to previous diagnostic
<leader>dShow diagnostic detail in float
<leader>qSend diagnostics to location list
<leader>twToggle warning inline hints on/off
Git (gitsigns.nvim)
<leader>gpPreview git hunk diff inline
<leader>gsStage git hunk under cursor
<leader>grReset git hunk to HEAD
Gutter signs: ▎ added   ~ changed   _ removed — update automatically on save.
Comments (Comment.nvim)
gccToggle comment on current line
gcVisual Toggle comment on selection
gcipComment entire paragraph
gcOAdd comment line above cursor
gcoAdd comment line below cursor
todo-comments: FIXME TODO NOTE HACK WARN PERF auto-highlighted.
Auto-completion (blink.cmp)
Tab / ↓Insert Select next suggestion
Shift+Tab / ↑Insert Select previous suggestion
EnterInsert Confirm selected item
Ctrl+SpaceInsert Manually trigger completion
Ctrl+eInsert Dismiss completion menu
(ghost text)Grey preview of best suggestion inline
Treesitter Text Objects & Navigation (nvim-treesitter-textobjects)
Motion — Jump between code structures
]mJump to next method / function start
[mJump to previous method / function start
]MJump to next method / function end
[MJump to previous method / function end
]]Jump to next class start
[[Jump to previous class start
Select — Operator-pending (combine with v, d, y, c, >, etc.)
afVisual Select around function (including signature + braces)
ifVisual Select inside function body
acVisual Select around class
icVisual Select inside class body
aaVisual Select around argument / parameter
iaVisual Select inside argument / parameter
Swap — Reorder parameters without copy-paste
<leader>snSwap current parameter with next
<leader>spSwap current parameter with previous
Example: Standing on a Java method → press vaf to select the whole method → d to delete it, y to copy it, or > to indent it.
Java — LSP & Refactoring (nvim-jdtls)  Java Only
Running
<F5>Run Java app (Gradle → Maven → plain javac fallback)
<leader>rRun Java application (same as F5)
<leader>jtGradle / Maven task picker (interactive list in terminal split)
Imports & Code Generation
<leader>oiOrganize imports — remove unused, resolve missing
<leader>jgGenerate code — toString, hashCode/equals, getters/setters, constructors
Refactoring
<leader>rvExtract variable (also works on visual selection)
<leader>rmExtract method (also works on visual selection)
<leader>rcExtract constant
Testing (requires java-test extension in nvim-tools)
<leader>tcRun entire test class
<leader>tmRun nearest test method under cursor
Debugger (DAP)  Java Only
Session Control
<F8>Continue / Start debug session
<leader>dcContinue debug session
<leader>dxTerminate debug session
<leader>drOpen debug REPL console
<leader>duToggle DAP UI panels
Breakpoints
<F9>Toggle breakpoint on current line
<leader>dbToggle breakpoint (same as F9)
Stepping
<F10>Step over (next line)
<F11>Step into (enter called method)
<F12>Step out (return from current method)
Window Management
Opening Splits
Ctrl+w sHorizontal split (also :sp)
Ctrl+w vVertical split (also :vs)
Navigation
Ctrl+w hMove to left window
Ctrl+w lMove to right window
Ctrl+w jMove to window below
Ctrl+w kMove to window above
Resizing
Ctrl+w =Equalise all window sizes
Ctrl+w >Increase width
Ctrl+w <Decrease width
Ctrl+w +Increase height
Ctrl+w -Decrease height
Ctrl+w _Maximise height
Ctrl+w |Maximise width
Closing
Ctrl+w qClose current window
Ctrl+w oClose all other windows (keep only this)
:qaQuit all windows
Config: New splits open below and to the right by default.
Buffer Management
:bn / :bnextNext buffer
:bp / :bprevPrevious buffer
:bdDelete (close) current buffer
:b#Toggle to last used buffer
<leader>fbTelescope buffer picker
:wSave buffer (triggers auto-format)
:waSave all open buffers
General & Miscellaneous
<Esc>Clear search highlight
y / pYank / paste — uses system clipboard
u / Ctrl+rUndo / Redo (persistent across sessions)
:e $MYVIMRCOpen init.lua config file
:LazyOpen lazy.nvim plugin manager UI
:Lazy syncInstall / update all plugins
:TSUpdateUpdate treesitter parsers
:checkhealthNeovim health diagnostics
File Explorer (oil.nvim)
-Open parent directory as editable buffer
EnterOpen file or enter directory
-Go up to parent (press again)
_Open CWD (project root)
g?Show all oil keymaps (help)
gxOpen with system default application
:w (in oil)Commit all pending renames / deletes / moves
Tip: Edit filenames to rename. Delete lines to delete files. All changes apply on :w.
Which-key & Smart Auto Features
which-key.nvim
<leader> (pause)Popup guide shows all keymaps after 500ms
Ctrl+w (pause)Shows all window management options
nvim-autopairs
( [ { " 'Insert Auto-closes matching bracket/quote
EnterInsert Smart expand between brackets
BackspaceInsert Deletes both pair characters at once
Automatic behaviours
(any yank)Yanked region briefly flashes yellow
(any :w)fidget.nvim shows LSP indexing spinner
:s/find/replaceLive preview in a split (inccommand=split)
Search & Replace
/patternSearch forward
?patternSearch backward
n / NNext / previous match
*Search word under cursor (forward)
#Search word under cursor (backward)
:%s/old/new/gReplace all in file (live preview in split)
:s/old/new/gReplace all in current line
:%s/old/new/gcReplace all with confirmation each time
<leader>fgTelescope grep — search across entire project
<Esc>Clear search highlights
Codeforces / CP (CompetiTest)
Competitive Companion
<leader>cpReceive problem from browser extension (port 27121)
<leader>ccReceive full contest problems into files
Running & Testing
<leader>crRun all testcases in interactive split with diff
<leader>caAdd custom testcase
<leader>ceEdit existing testcase
<leader>cdDelete testcase
Workflow: Click green plus on Codeforces problem → auto-loads into Neovim → <leader>cr runs and checks outputs!
