- brew uninstall NAME       Remove a formula.

- NVM version: 0.40.1
- Active/default Node.js: 22.23.1
- npm version: 10.9.8

TOOLS AND CHANGES ADDED BY CODEX
--------------------------------

ble.sh 0.3.4
- Inline suggestions from Bash history.
- Live command syntax highlighting.
- Use Right Arrow to accept a visible suggestion.

Starship 1.23.0 configuration
- Compact VS Code-black themed Ubuntu prompt.
- Shows directory, Git branch/status, slow-command duration, failures and time.
- Git information only appears while inside a Git repository.

fzf 0.44.1
- Ctrl+R: fuzzy command-history search.
- Ctrl+T: fuzzy file selection into the command line.
- Alt+C: fuzzy folder selection and navigation.

zoxide 0.9.3
- Learns frequently visited directories.
- z PROJECT               Jump to a matching remembered directory.
- zi                      Select a directory interactively.

eza 0.18.2
- Modern replacement for `ls`.
- ls                      Normal icon-aware listing.
- ll                      Detailed listing, hidden files and Git status.
- la                      Listing including hidden files.
- lt                      Two-level directory tree.

Git and Lazygit
- lg                      Open the Lazygit full-screen Git interface.
- gs                      Short Git status and current branch.
- gl                      Last 20 commits as a decorated graph.
- gd                      Show unstaged changes.
- gds                     Show staged changes.
- Lazygit version: 0.63.1, installed from its official verified release.

Search and file viewing
- fd NAME                 Quickly find files by name.
- rg TEXT                 Search file contents recursively.
- bat FILE                View a file with syntax highlighting and line numbers.

System monitoring
- top                     Opens btop instead of the old top interface.
- btop                    Opens the same modern system monitor directly.


EVERYDAY EXAMPLE
----------------

cd ~/my-project
gs                         Check branch and changed files.
ll                         Inspect files and their Git state.
lg                         Stage, commit, pull and push interactively.
rg "search text"          Search the project contents.
z project-name             Jump back to a remembered project.

Node packages:
