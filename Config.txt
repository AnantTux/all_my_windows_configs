## PowerShell 7

PowerShell 7 is used automatically by Alacritty and when you select the **PowerShell** profile in Windows Terminal.

Features currently active:

- UTF-8 support for icons and modern tools
- Starship prompt
- Command history suggestions displayed as a list
- Up/down arrows search matching history
- `Ctrl+R` opens fuzzy command-history search
- `z project` jumps intelligently to frequently visited folders
- `ls` uses modern coloured `eza` listings
- `ll` gives detailed listings
- `la` includes hidden files
- `lt` displays a two-level file tree
- `lg` opens Lazygit
- `top` opens Bottom system monitor
- `fetch` displays Fastfetch system information
- `y` opens Yazi and remembers its final directory
- `ff` fuzzy-finds a file, previews it with Bat, then opens it in Neovim
- `lvim` launches your LunarVim command

Config: [PowerShell 7 profile](<C:/Users/kaura/OneDrive/Documents/PowerShell/Microsoft.PowerShell_profile.ps1>)

## Starship prompt

Your prompt uses the same VS Code-inspired black palette as Alacritty and Neovim.

It displays:

- Current directory
- Git branch and repository status
- Command duration for commands over 1.5 seconds
- Previous command’s error status
- Current time
- Green or red prompt indicator
- Nerd Font folder, Git, lock, timer, and clock icons

Config: [starship.toml](<C:/Users/kaura/.config/starship.toml>)
