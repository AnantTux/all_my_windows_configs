CONFIG BACKUP RESTORE PATHS

Backup folder:

HOW TO RESTORE A FILE
---------------------

1. Close the application that uses the configuration.
2. Make a copy of the current live file before replacing it.
3. Open this backup folder and locate the file in the left column below.
4. Copy it to the destination in the right column and allow Windows to replace the file.
5. Restart the application.

You normally only need to restore the individual file that is broken.

WSL / UBUNTU CONFIGURATIONS
---------------------------

WSL files can be restored through File Explorer while Ubuntu is running.

Backup: WSL\Ubuntu\home\ubuntu\.bashrc
Paste at: \\wsl.localhost\Ubuntu\home\ubuntu\.bashrc

Backup: WSL\Ubuntu\home\ubuntu\.config\starship.toml
Paste at: \\wsl.localhost\Ubuntu\home\ubuntu\.config\starship.toml

After restoring .bashrc, open Ubuntu and run:
source ~/.bashrc
